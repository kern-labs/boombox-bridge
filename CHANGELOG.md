# Changelog

## 1.1.2 (2026-10-17)
- More robust playback: Stop before a new stream, retry with alternative media types and HTTP instead of HTTPS ("Can't play, no URI supplied")
- Red Boom Box colors in the web interface

## 1.1.0
- Resume the last station automatically after power off/on ("INVALID_SOURCE"), per speaker
- Remembers stations started from the Boom Box app as well

## 1.0.0
- Preset buttons 1–6 via local WebSocket + UPnP, no cloud
- Automatic speaker discovery (Bonjour), manual IP addresses
- Web interface with station search (radio-browser.info)
- HTTP API for the Boom Box app
